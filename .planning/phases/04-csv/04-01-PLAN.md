# Phase 4 Plan: CSV import (creators-messy.csv) + payout export

**Goal:** Pure, unit-tested CSV modules; import CLI reports per-row problems; export button in Ops UI downloads Excel-safe payout CSV.

## Decisions applied
- D5: month computed in Asia/Bangkok on `createdAt` (s3 → Sep, s4 → Oct). Explain in video; "approvedAt" is a NOTES fix.
- D6: amount = integer THB from `campaign.ratePerVideoTHB`, joined at export time.
- D7: UTF-8 BOM, comma, CRLF, quote fields with `, " \n`, prefix `'` on cells starting `= + - @ \t \r`. Columns: submissionId, creatorId, campaignId, campaignTitle, tiktokUrl, createdAt (ISO UTC), amountTHB. (creatorEmail dropped: not in submission data; avoids extra join.)
- D8: parser = pure module; CLI writes valid rows to `creators/{emailLower}` (idempotent upsert) and prints report; no upload UI (STUB, note in NOTES). Rules already deny client writes to `creators`; CLI uses Admin SDK on emulator.

## Expected import result (verify by running, not assume)
Real file (BOM header `\ufeffname`): 7 data rows → rows 2,3,4 OK; row 5 duplicate email (of row 2); row 6 empty name + invalid email (report BOTH reasons); row 7 formula name `=HYPERLINK(...)`; row 8 handle without `@`. Note real header is `tiktok_handle`. Line numbers must stay correct with multi-line quoted fields (track physical line of record start).

## Tasks
1. **CSV parser** `scripts/lib/csv.ts` (own RFC4180 parser: quotes, escaped `""`, CRLF, embedded newlines, strip BOM; track start line per record) + tests (quoted comma, Thai chars, multiline field line numbers).
2. **Creator validation** `scripts/lib/creators.ts` — `validateCreators(rows) → {valid[], errors[{line, reasons[]}]}` rules per D8 (name required, email regex + lowercase, duplicate by lowercase email → cite first line, handle starts with `@`, name/city starting `= + - @` rejected). Test against actual `data/creators-messy.csv` expecting the table above; re-run idempotency.
3. **Import CLI** `scripts/import-creators.ts` + `npm run import:creators` — prints report (line + reasons), writes valid rows with `importedAt`. Verify twice against emulator → same doc count.
4. **Payout export** `web/src/lib/payoutCsv.ts` — pure: `monthKeyBangkok(date)`, `buildPayoutCsv(submissions, campaigns, month)` (approved only, escape + neutralize). Tests: 2026-09 → only s3 (800) ; 2026-10 → only s4; UTC boundary case s4; s6 paid/s1/s2/s5 excluded; BOM present (first bytes EF BB BF); `=cmd`, URL with comma/quote handled.
5. **Ops UI** — month picker + "Export payout CSV" (Blob download with BOM). Reuse queue data; query `status == 'approved'`.
6. **Evidence** — unit test output, CLI report, open exported file in Excel/LibreOffice (Thai OK, `=` not executed); record in TEST-PLAN C & D; STATE F4; commits per module.
