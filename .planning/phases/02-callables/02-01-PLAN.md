# Phase 2 Plan: Callables (reviewSubmission, markPaid) + tests

**Goal:** `npm run test:functions` green, covering TEST-PLAN B1–B12, incl. 10-way parallel approve → exactly 1 `changed:true` and 1 auditLog.

## Contract (ARCHITECTURE.md, D4)
- `reviewSubmission({id, decision:'approved'|'rejected', reason?})`, `markPaid({id})` → `{ok:true, changed, status}`
- Check order: auth → ops claim → input validation → transaction (get → state check → update + auditLog).
- Errors: unauthenticated, permission-denied, invalid-argument (bad decision / reject w/o trimmed reason / reason >500), not-found, failed-precondition.
- Same-target repeat → ok, `changed:false`, no new auditLog.
