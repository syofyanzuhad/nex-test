# Phase 3 Plan: React UI (Ops queue, Creator form + list)

**Goal:** Vite + React 19 + TS app in `web/` against emulators; `npm run dev` works; manual smoke checklist (TEST-PLAN F) passes incl. deliberate failures.

## Constraints
- D1: hooks only, no router/state library. Styling free, keep minimal.
- Errors from callables/rules must be readable (R3.3), never "internal"/stack traces. i18n comes in Phase 5, but write user-facing strings in one `messages` place now so Phase 5 only swaps source (AGENTS: error messages via i18n).
- Creator list query MUST include `where('creatorId','==',uid)` (rules deny otherwise).
- After login call `getIdToken(true)` so `ops` claim is present (D2).
- Client URL validation is UX only; rules are authority. Regex must accept `vm.tiktok.com/ZSabc123/`, reject `tiktok.com.evil.com`.

## Tasks
1. **Scaffold** `web/` (Vite react-ts), firebase client init with emulator connect (auth 9099, firestore 8080, functions 5001, project demo-nex); root script `dev`.
   - verify: `npm run dev` serves page.
2. **Login** — pick seeded user (ops-1, creator-a, creator-b; password from seed script), sign in, force token refresh, show role from claim.
3. **Pure helpers + tests** `web/src/lib/` — `validateTiktokUrl`, `mapError(code)→message`; Vitest unit tests (valid/invalid URLs incl. evil domains; error mapping for permission-denied, failed-precondition, not-found, unknown).
4. **Creator page** — form (campaign select from open campaigns + URL), validation message, `addDoc` with `serverTimestamp`, list own submissions; loading/empty/error states.
5. **Ops page** — queue via query, filters status + campaign, approve / reject (reason modal blocks empty), calls `reviewSubmission`; loading/empty/error; double-click safe (disable while pending, no-op result shown gracefully).
6. **Evidence** — run TEST-PLAN F checklist manually incl. forced failures (invalid URL; rules denial e.g. closed campaign; emulator off → error state; two-tab approve). Record in TEST-PLAN.md; STATE F3; commits per screen.

## Risks
- Real seed has no closed campaign → to test rules denial, create one via Emulator UI/admin script (document, don't add to seed).
- Firestore composite index needed if filter combines status + campaign + order; emulator reports it.
- Export CSV button belongs to Phase 4, not here.

## Done when
- [ ] R3.1–R3.3 demonstrably met  - [ ] helper unit tests green  - [ ] F-checklist evidence recorded  - [ ] user answers 3 "what if" questions first
